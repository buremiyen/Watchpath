# Contributing to Watchpath

Thanks for your interest in improving Watchpath.

## Local setup

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Before opening a pull request

- Keep the interface responsive on desktop and mobile.
- Preserve existing local progress data where possible.
- Add UI text through `app/i18n.ts` so every supported language stays complete.
- Avoid committing secrets, API keys, passwords, tokens, or private user data.
- Keep copyrighted brand assets out of the repository unless their use is permitted.
- Prefer small, focused pull requests with a clear description.

## Commit style

Short conventional-style messages are preferred, for example:

- `feat: add marathon filter`
- `fix: preserve progress after import`
- `style: polish mobile navigation`
- `docs: update setup guide`

## Reporting bugs

Please include:

1. Browser and device
2. Steps to reproduce
3. Expected behavior
4. Actual behavior
5. Screenshot or screen recording when useful
