# Watchpath 🎬

A smart movie & TV marathon planner that adapts to your watching progress.

## Current MVP

- Doomsday marathon dashboard and countdown
- Movie posters and runtime/platform metadata
- Watched/unwatched tracking persisted in localStorage
- Expandable TV series with season/episode tracking
- Progress statistics
- Today / Titles / Calendar navigation
- Responsive mobile-first interface
- PWA manifest foundation

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Roadmap

Next steps include completing the Marvel/X-Men dataset, true date-based adaptive scheduling, filters/search, TMDB-backed metadata, PWA icons/offline support, additional marathon packs and cloud sync.
